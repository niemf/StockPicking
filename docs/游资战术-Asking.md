# 游资战术 v0：把 Asking 语录翻译成程序

> 来源：[A股之神 Asking 语录](https://www.xiarj.com/28408.html)（邱宝裕，闽发论坛）。
> 原则：**只翻译能机械判定的部分**；不可判定的明确标注，不硬凑。

---

## 一、语录里真正能用的六条

| # | 原话 | 翻译成什么 | 数据 |
|---|---|---|---|
| 1 | "对势的理解超过一切" / "借大盘的势" | **环境闸门**：指数在下跌通道时不开新仓 | 指数收盘 vs MA20 / MA60、MA20 斜率 |
| 2 | "有量就能来钱，好坏只有一个标准——量" | **量能状态**：全市场成交额 5 日均 / 20 日均 | `market_daily.amount_yi` |
| 3 | "相对低位的第一根放量大阳线" | **位置 + 形态**：距 60 日高 <85%，当日涨 >5%，量比 >1.5 | `indicator_daily` |
| 4 | "第一次放量上穿 5 日线" | **触发**：昨日收盘 < 昨日 MA5，今日收盘 > MA5 且放量 | `ma5` 当日/前一日 |
| 5 | "90% 以上的操作第二天结束" | **持有期**：1–5 天，不做趋势 | 回测参数 |
| 6 | "弱市只做极度超跌后的反弹" | **例外条款**：指数 10 日跌幅 >8% 且放量 → 允许抢反弹 | 指数日线 |

对应到代码：

```python
# 已实现：app/analysis/factors.py
low_position   : close / high60_prev < 0.85
launch_candle  : pct_chg >= 5% and volume_ratio >= 1.5
                 and prev_close < prev_ma5 <= ma5 < close
```

策略档：`app/analysis/profiles/youshi.yaml`（关掉追高类条件，目标固定 2R，默认持有 5 天）。

## 二、不可机械化的部分（不要假装能写进代码）

| 原话 | 为什么不行 |
|---|---|
| "能否成为龙头，要看是否具备当前容易被市场认可的题材" | 需要语义理解，只能 AI 辅助 |
| "真抗跌要大涨，假抗跌要补跌，全靠经验" | 需要盘中分布与筹码判断 |
| "午间拉高的个股，开盘后常是当日高点" | 需要分时/逐笔数据 |
| "心态、控制力占 7 分" | 不可编程 |
| "看对三日行情便富可敌国" | 这是目标，不是规则 |

## 三、战术的算法结构（六层）

```
第 1 层  环境（能不能做）
        上证 < MA20 且 MA20 下行 → 只允许「超跌反弹」，其余全部放弃
        全市场成交额 5/20 日均 < 0.8 → 降低仓位、减少出手

第 2 层  板块（做哪个方向）
        板块 5 日资金净流入 + 板块内涨停数增加 + 板块涨幅排名前 5
        （当前只有当日板块资金，历史不足，暂未接入回测）

第 3 层  位置（做哪只）
        距 60 日高 < 85%（相对低位）、20 日涨幅 < 20%、距 MA20 < 8%

第 4 层  触发（什么时候买）
        首次放量上穿 MA5：涨幅 ≥5%、量比 ≥1.5、昨日收盘 < MA5

第 5 层  风控（买多少、错了怎么办）
        止损 = min(价 − 1.2×ATR, MA20×0.99)，单笔风险 0.5–1%
        目标 = 2R（游资的"第二天了结"对应短持有）
        盈亏比 < 2 不开仓

第 6 层  纠错（第二天怎么办）
        T+1 不涨即走；跌破止损无条件走；不补仓、不摊薄
```

## 四、v0 回测结果（2025-12-25 ~ 2026-08-15，154 个交易日）

| 指标 | 现漏斗 | 游资战术 v0 |
|---|---|---|
| 成交 | 1485 笔 | **437 笔** |
| 胜率 | 32.5% | **42.6%** |
| 期望 | −0.17R | **−0.04R** |
| 盈亏因子 | 0.67 | **0.93** |
| 最大回撤 | 267R | **54R** |
| 平均持有 | 6.9 天 | 3.5 天 |
| **选股 alpha** | **−0.42%** | **−0.00%** |

结论：

1. **把"追高"换成"低位启动"，负 alpha 消失了**（−0.42% → 0.00%），说明伤害确实来自买在高位；
2. 但仍然只是**打平市场**，扣 0.26% 成本后 −0.04R；
3. 胜率 42.6% 配 1.11R/0.89R 的盈亏比，距离转正只差一点（需要平均盈/亏 ≥1.35）。

**这是目前最接近可用的一版，但还没通过验收线，不能上线。**

## 五、AI 基本面闸门（设计，尚未接入）

用户要求"不能空谈，要结合基本面"。但基本面有两个现实约束：

1. 我们**没有历史基本面数据**，无法回测；
2. Asking 自己也说"题材比基本面重要得多"。

所以定位应该是**排除法（veto）而不是选股**：

```
输入：代码、名称、行业、近 30 天公告标题+类型、20 日涨幅、成交额、板块资金方向
输出（JSON）：verdict(pass/veto)、tags(题材)、reasons、confidence
veto 条件：减持/解禁/预亏/问询函/立案/商誉减值/高质押/退市风险
成本：15 只/天 × ~1.5k tokens ≈ ¥0.05/天，远低于预算
缓存：同一 (code, trade_date) 只调一次
```

**明确声明**：这一层是"避雷"，不是"alpha 来源"，也不能被回测验证。上线时只作为否决票，
不参与打分。

后续可选数据（免费、一次请求拿全市场）：`ak.stock_zh_a_spot_em()` 提供市值/PE/PB/换手，
可落一张 `stock_valuation` 表，给 AI 提供估值背景。

## 六、与回测数据的冲突（必须记住）

Asking 说"指数走下跌通道时，符合条件的交易全部放弃"。我们用 211 天测过：

```
指数 > MA20 才持有：−18.9%
指数 < MA20 才持有：+5.8%（夏普 0.45）
```

在这段样本里，"弱市不做"会让你错过所有反弹。可能的原因：他做的是 2000 年代的日内超短，
我们做的是日线 5 日持仓；市场结构不同。

**处理方式**：第 1 层环境闸门默认只做"降仓"，不做"完全空仓"；等更长样本再决定。
