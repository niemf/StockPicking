# 策略选股页面设计（预留，暂不实现）

> 目标：在 Web 端把技术指标做成可勾选、可调阈值的策略，运行后得到候选列表。
> 当前 D 阶段已经把"策略配置（profile）"和"执行（pipeline）"解耦，本页面只是配置的生产者。

## 1. 页面结构

```
策略选股 /screener
├── 策略模板      趋势突破 | 低吸回踩 | 放量启动 | 自定义
├── 基础池        主板 / 非ST / 上市天数 / 最小成交额
├── 硬性条件      趋势、量价、动量、波动、风险（每项一个开关 + 参数）
├── 评分权重      趋势 30 / 量价 25 / 动量 20 / 相对强度 15 / 波动 10
├── 输出          候选数量、排序方式
└── 运行          预览前 30 只 → 保存为自选 / 导出
```

交互上用开关 + 数值输入，不需要写 YAML。每个因子旁显示一句说明和默认值。

## 2. 数据模型（新增）

```text
screen_profile
  id INTEGER PK
  name TEXT
  config JSON          -- 与 app/analysis/profiles/default.yaml 同结构
  is_default INTEGER
  created_at DATETIME
  updated_at DATETIME

screen_run
  id INTEGER PK
  profile_id INTEGER
  trade_date DATE
  stats JSON           -- 复用 pipeline 的漏斗统计
  created_at DATETIME
```

候选结果仍然写入现有 `candidate` 表，`screen_run.id` 可后续加字段关联，避免复制一套结果表。

## 3. 因子元数据

为了让前端自动渲染表单，每个因子需要暴露 UI 元数据：

```python
@hard_filter(
    "volume_ratio",
    4,
    "量比",
    requires=("volume_ratio",),
    ui={"type": "range", "min": 0.5, "max": 5.0, "step": 0.1, "default": [1.2, 3.0]},
)
```

注册表新增 `describe_factors()`，返回：

```json
{
  "filters": [
    {"key": "ma20_trend", "label": "MA20 向上", "stage": 3, "ui": {...}},
    {"key": "volume_ratio", "label": "量比", "stage": 4, "ui": {...}}
  ],
  "scorers": [
    {"key": "trend", "label": "趋势强度", "default_weight": 30}
  ]
}
```

前端按 stage 分组渲染，新增因子自动出现在页面上，不需要改前端代码。

## 4. API 草案

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/screener/factors` | 返回因子元数据 + 默认 profile |
| GET | `/api/screener/profiles` | 策略列表 |
| POST | `/api/screener/profiles` | 保存策略 |
| PUT | `/api/screener/profiles/{id}` | 修改策略 |
| POST | `/api/screener/run` | `{profile_id}` 或 `{config}`，返回漏斗与候选 |
| GET | `/api/screener/runs` | 运行历史 |

运行接口复用 `run_discovery(profile=config)`，不复制筛选逻辑。

## 5. 性能策略

- 收盘后把每只股票的关键指标写入现有 `indicator_daily`，并缓存 `StockContext` 的特征帧；
- 自定义策略基于缓存指标执行，全市场应在 1–3 秒内返回；
- 如果用户修改的是"日线级"阈值（如 MA20 周期），需要重算特征；如果是权重/评分变化，直接复用；
- 一次运行只做一次行情快照，多个策略共用同一份快照。

## 6. 模板预设

| 预设 | 特点 | 主要开关 |
|---|---|---|
| 趋势突破 | 顺势、追强势 | MA20 向上、突破 20 日新高、量比 1.2–3 |
| 低吸回踩 | 强趋势中的回调 | 价格在 MA20 ±2%、缩量、RSI 40–60 |
| 放量启动 | 底部/平台放量 | 量比 ≥ 2、突破平台、MACD 金叉 |
| 稳健蓝筹 | 低波动、流动性好 | 市值/成交额更高、ATR ≤ 4%、回撤小 |

预设只是 `config` 的不同默认值，不新增代码路径。
