# 策略规则库（研究蒸馏版）

> 目的：把「技术分析经典 + 游资实战经验 + 情绪周期」整理成**程序可判定**的规则，
> 每条规则都要能回答三个问题：用什么数据算、阈值是多少、回测期望够不够上线。

## 0. 分层原则

短线盈利的因果链不是「指标 → 买点」，而是：

```
情绪周期（今天该不该做、做多重）
  └─ 结构（钱在哪个方向：趋势/平台/回踩）
       └─ 信号（这一笔的入场时点：金叉、反包、突破确认）
            └─ 风控（止损、目标、盈亏比、仓位）
```

单独把「MACD 金叉」当买点，公开回测结果是胜率 52%、年化 −8%
（[技术指标的真实角色·第 04 课](https://waylandz.com/quant-book/)）。
所以本规则库里，**指标只出现在第三层**，前两层只做「允许/禁止」和「结构识别」。

## 1. 情绪周期（择时层，最高优先级）

### 1.1 五个观测量（全部可由现有数据算出）

| 指标 | 定义 | 数据来源 |
|---|---|---|
| `limit_up` | 主板涨停家数 | 全市场行情快照（`price >= limit_up`） |
| `limit_down` | 跌停家数 | 同上 |
| `break_rate` | 炸板率 = 触板未封 / 触板总数 | 快照（`high >= limit_up` 但 `price < limit_up`） |
| `max_streak` | 最高连板高度 | 涨停池 `stocks[].streak` |
| `prev_premium` | 昨日涨停股今日平均涨跌幅（赚钱效应） | 昨日涨停池 + 今日快照 |
| `breadth` | 上涨家数占比 | `sentiment.compute()` |

`prev_premium` 是最重要的一个：它衡量的是「昨天打板的人今天赚不赚钱」，
比涨停家数更早反映情绪拐点。

### 1.2 阶段划分（阈值可配置）

| 阶段 | 判定（满足任一主条件 + 辅助确认） | 含义 |
|---|---|---|
| **冰点** | `limit_up ≤ 25` 且 `prev_premium < -1` 且 `break_rate ≥ 0.45` | 亏钱效应极致，恐慌尾声 |
| **退潮** | `prev_premium < -2`，或 `limit_up < 前日 × 0.6` 且 `break_rate ≥ 0.35` | 高位分歧后杀跌，接力必亏 |
| **高潮** | `limit_up ≥ 90` 或 `max_streak ≥ 6`，且 `prev_premium > 3` | 一致性过强，随时反水 |
| **发酵** | `limit_up ≥ 50` 且 `prev_premium > 1` 且 `break_rate < 0.35` | 主升段，可正常做 |
| **修复** | 其余情况 | 分歧/轮动，结构性机会 |

参考：炒股养家「冰点→启动→发酵→高潮→退潮」四段式，以及淘股吧流传的冰点判据
（涨停 <20、跌停 >10、连板高度 ≤2、昨日涨停今日红盘 <30%、炸板率 >50%）。

### 1.3 每个阶段对应的**动作**（这才是规则库的价值）

| 阶段 | 建议总仓位上限 | 候选池 RR 下限 | 选股偏好 |
|---|---|---|---|
| 冰点 | 40% | 2.0 | 只做首板/超跌反包，禁止接力 |
| 修复 | 60% | 2.0 | 趋势回踩、平台突破回踩 |
| 发酵 | 80% | 2.0 | 主流题材中军、二波反包 |
| 高潮 | 40% | 3.0 | 不追高，只做首阴低吸 |
| 退潮 | 20% | 3.5 | 空仓为主，只留观察 |

「买在冰点、卖在高潮」对应的是**仓位**，不是「冰点无脑买」——
冰点期只允许试仓，且必须满足更高的结构要求。

## 2. 量价结构（选股层）

经典量价八/九种组合 + 可量化阈值（缩量 = 较前 5 日均量萎缩 20% 以上，
即 `volume_ratio < 0.8`）：

| # | 规则 | 机器判定 | 用途 |
|---|---|---|---|
| 1 | 量增价涨（健康多头） | `volume_ratio ∈ [1.2, 2.5]` 且 `pct_chg > 0` 且 `close_position > 0.6` | 加分 |
| 2 | 量缩价涨（动能衰退） | `volume_ratio < 0.8` 且 `close > ma20 × 1.08` | 减分/不追 |
| 3 | 量增价跌（高位派发） | `volume_ratio > 2.0` 且 `pct_chg < 0` 且 `close < high20 × 0.98` | 排除 |
| 4 | 放量滞涨 | `volume_ratio > 2.5` 且 `close_position < 0.5` | 排除（已上线） |
| 5 | 长上影派发 | `upper_shadow_pct > 4` 且 `volume_ratio > 1.5`，近 3 日出现 ≥1 次 | 排除（已上线） |
| 6 | 突破确认（不追突破日） | 前 20 日振幅 <15%，`price > high20_prev × 1.005` 且 `volume_ratio > 1.5`，**次日回踩不破突破位**才买 | 入场 |
| 7 | 缩量回踩不破 | 价格回到 `ma10 ± 2%`，`volume_ratio < 0.8`，`close ≥ ma20` | 入场 |
| 8 | 二波反包 | 首波涨幅 15–40%，回调 3–8 日且量能缩到 50%，`close > 前高 × 0.98` 且当日阳线 | 入场 |

规则 1–5 是**过滤器**（已部分上线），6–8 是**入场结构**（待实现 + 回测）。

## 3. 指标信号（入场时点层）

| 规则 | 机器判定 | 备注 |
|---|---|---|
| 零上金叉 | `macd_dif > 0` 且上穿 `dea`（前一日 `dif ≤ dea`） | 比零下金叉可靠；零下金叉只做反弹 |
| 零轴首次金叉 | 金叉且 `dif` 由负转正 | 力度最强，但一年次数很少 |
| 顶背离 | 价格创 20 日新高，`dif` 未创新高，且 `hist` 转负 | 卖出/不追，不做空 |
| 葛兰碧法则 | 价格回踩 MA20 不破 + MA20 向上 → 买；跌破且 MA20 走平 → 卖 | 与规则 7 重合 |
| 均线多头排列 | `ma5 > ma10 > ma20 > ma30` 且 `ma20_slope3 > 0` | **只作为状态，不作为买点**（本次已确认） |

## 4. 游资手法（观察层，不做执行）

| 手法 | 公开要点 | 我们怎么用 |
|---|---|---|
| 龙头战法 | 龙头必须从涨停开始；买分歧、卖一致 | 用涨停池 + 连板高度判断「谁是真龙」，只做**观察名单** |
| 首阴低吸 | 至少 2 个涨停、最后涨停有跳空、首阴缩量且不破 MA5 | 作为「高潮期唯一允许的结构」，需分时数据，暂缓 |
| 晋级率 | 昨日首板今日晋级二板比例 | 进情绪周期指标（后续加） |
| 龙虎榜席位 | 知名席位净买额、买方集中度 | 作为**评分因子**，不做硬门槛 |

**明确不做**：集合竞价抢筹、盘口封单/撤单、首板打板、连板接力。
原因：T+1 + 60 秒轮询 + 日线数据，执行层面根本来不及，写进程序只会得到
「看起来能赚、实际成交不了」的假回测。

## 6. 上线验收标准

1. 规则必须写成 `strategy` 类，输入 `StockContext`，输出 `Signal(entry, stop, target, rr, reasons)`；
2. 用 2025-12-25 至 2026-11-12 的 215 个交易日回测：T 日收盘出信号，T+1 开盘/限价买，按日线判止损/目标，含滑点 0.1% + 手续费；
3. 样本 ≥ 30 笔、期望 ≥ 0.2R、最大回撤 < 15%，才允许进候选池；
4. 前 70% 调参、后 30% 验证；参数不接受「后视镜调优」；
5. 情绪周期作为**共同前提**参与回测分组：同一策略在「发酵/修复」与「退潮」的期望必须分开统计。
