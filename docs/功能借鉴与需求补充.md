## 3. 明确不做（避免跑偏）

| 不做 | 原因 |
|---|---|
| TradingAgents 式多 Agent 辩论 | 单次 3–5 分钟、成本高，个人场景收益低 |
| 全市场 AI 研报 | 3000+ 只不可能，只做「候选 Top 30 + 自选」 |
| 港股/美股/ETF 扩展 | 先把 A 股主板做扎实 |
| 券商交易接口 / 自动下单 | 合规与风险都不划算 |
| 同花顺账户自动登录 | 不稳定，已放弃 |
| 收费荐股 / 收益承诺 | 合规红线 |

## 5. 数据源与缓存注意

| 数据 | 来源 | 缓存 |
|---|---|---|
| 涨跌家数/涨跌停 | 复用全市场快照 | 快照级（180s / 盘后一次） |
| 板块资金 | 东财 `stock_sector_fund_flow_rank`，失败降级新浪板块涨幅 | 按日，30 分钟 TTL |
| 个股资金流 | 东财 `stock_individual_fund_flow`，失败降级新浪 `MoneyFlow` | 按 代码+日期，3 小时 TTL |
| 涨停梯队 | 东财 `stock_zt_pool_em`（连板数/封板资金/炸板） | 按日，盘中 10 分钟 / 盘后 6 小时 |
| 龙虎榜席位 | 东财 `stock_lhb_hyyyb_em`（活跃营业部） | 按日，6 小时 |
| 新闻/公告 | 巨潮 JSON（公告）；新闻未接 | 公告按日 6 小时 TTL |

东财接口有限流，所有新增数据一律**按日/按小时落盘缓存**，失败降级不阻塞页面；失败后 10 分钟内不重复请求同一接口。

## 6. AI 成本约束（沿用现有机制）

- 只对「候选 Top N + 用户自选」生成报告，按 代码+交易日+prompt 版本 缓存；
- 盘前简报只发结构化摘要，不额外调用 AI（或复用昨日复盘）；
- 每份报告标注数据时间与来源；
- 预算护栏继续生效（当前实测：单份计划约 ¥0.005，复盘约 ¥0.014）。
