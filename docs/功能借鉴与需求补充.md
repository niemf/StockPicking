# 功能借鉴与需求补充（个人版优先）

> 状态：**草案，待你选优先级**
> 日期：2026-11-11
> 调研对象：daily_stock_analysis、PanWatch、go-stock、StockGoose、TrendRadar
> 结论：第一版仍做**个人版**，持仓默认关闭，飞书优先，页面游客可读。

---

## 1. 我们已有什么

| 能力 | 状态 |
|---|---|
| 自选 CRUD、建仓区间 | ✅ 有 |
| 持仓 / 成本 / 盈亏 | ✅ 有（**默认关闭**） |
| 盘中 120s 轮询 + 预警状态机（确认/冷却/重武装/去重） | ✅ 有 |
| 飞书卡片 + 邮件兜底 | ✅ 有 |
| 日线、前复权、全市场发现、候选池 | ✅ 有 |
| 指标/因子注册式扩展 | ✅ 有 |
| AI 交易计划（草稿→人工确认） | ✅ 有 |
| 每日复盘（大盘/板块资金/龙虎榜/操作） | ✅ 有 |

## 2. 优先级建议

### P0：先做，直接提升日常使用价值

| # | 功能 | 借鉴 | 为什么 | 难度 |
|---|---|---|---|---|
| 1 | **条件组合预警**：AND/OR（价格、涨跌幅、成交额、量比）、日触发上限、到期时间、仅交易时段、按规则选渠道 | PanWatch | 现在只有单一价格线，容易漏报或反复轰炸 | 中 |
| 2 | **自选分组 + 标签 + 拼音搜索 + 批量导入导出** | go-stock / StockGoose | 自选一多就难管；CSV 导入省手工 | 低 |
| 3 | **结构化 AI 个股报告卡**：结论/评分/趋势/关键价位/风险/催化/操作清单 | daily_stock_analysis | 现在的计划 JSON 偏交易参数，不够“研报感” | 低 |
| 4 | **盘前简报（08:45）**：昨日复盘 3 条 + 今日关注 + 自选关键价位 | PanWatch / go-stock | 现在只有盘后，早上没有决策输入 | 低 |
| 5 | **市场情绪卡片**：涨跌家数、涨停/跌停数、总成交额、连板高度 | daily_stock_analysis / go-stock | **复用已有 3195 只快照，几乎零成本** | 低 |

> 第 5 条性价比最高：一次批量快照已经在拉，顺手就能算出涨跌家数/涨跌停，不用额外接口。

### P1：第二梯队，增强分析深度

| 10 | PWA（添加到主屏、后台通知） | PanWatch / StockGoose | 手机体验接近 App，不用上架 | 低 |

## 3. 明确不做（避免跑偏）

| 不做 | 原因 |
|---|---|
| TradingAgents 式多 Agent 辩论 | 单次 3–5 分钟、成本高，个人场景收益低 |
| 全市场 AI 研报 | 3000+ 只不可能，只做「候选 Top 30 + 自选」 |
| 港股/美股/ETF 扩展 | 先把 A 股主板做扎实 |
| 券商交易接口 / 自动下单 | 合规与风险都不划算 |
| 同花顺账户自动登录 | 不稳定，已放弃 |
| 收费荐股 / 收益承诺 | 合规红线 |

## 5. 数据源与缓存注意

| 数据 | 来源 | 缓存 |
|---|---|---|
| 涨跌家数/涨跌停 | 复用全市场快照 | 快照级（120s / 盘后一次） |
| 个股资金流 | AkShare `stock_individual_fund_flow` | 按 代码+日期，盘后一次 |
| 涨停梯队 | 快照 + 涨停价规则 | 同上 |
| 龙虎榜席位 | AkShare 龙虎榜营业部接口 | 按日 |
| 新闻/公告 | AkShare 公告 + RSS | 按小时，去重 |

东财接口有限流，所有新增数据一律**按日/按小时落盘缓存**，失败降级不阻塞页面。

---

## 6. AI 成本约束（沿用现有机制）

- 只对「候选 Top N + 用户自选」生成报告，按 代码+交易日+prompt 版本 缓存；
- 盘前简报只发结构化摘要，不额外调用 AI（或复用昨日复盘）；
- 每份报告标注数据时间与来源；
- 预算护栏继续生效（当前实测：单份计划约 ¥0.005，复盘约 ¥0.014）。

## 7. 建议的下一步

**先做 P0 的 1 + 2 + 5**：预警更准、自选好管、首页有情绪。三条都不依赖新数据源，改动可控。

做完再上 3 + 4（AI 报告卡 + 盘前简报），形成“早上看计划、盘中收提醒、晚上看复盘”的完整闭环。
